== Application Lifecycle (Application Lifecycle management use case)

Application Lifecycle functionality in RHACM provides processes to manage application resources on your managed clusters. It allows you to define a single or multi-cluster application using Kubernetes specifications, with additional automation for deployment and lifecycle management.

=== Deploying Argo CD

.Prerequisites:
* On the `local-cluster`, ensure the label `rhdp_usage=development` is present.
* On the new cluster you provisioned, ensure the label `environment=prod` is present.

. In RHACM, switch to the `local-cluster` view.
. Navigate to *Operators -> OperatorHub* and search for *OpenShift GitOps*.
. Click on the Operator and click *Install*. Leave all defaults and click *Install*. This may take up to 7 minutes.
+
image::install-gitops-operator.png[Installing the OpenShift GitOps Operator]

. Once installed, you may need to refresh the web console. You can then access the Argo CD UI from the application launcher icon in the top-right corner.
+
image::argo-cd-launcher.png[Accessing Argo CD from the application launcher]

. On the Bastion host, apply the following Group to give the `admin` user permissions in Argo CD.
+
[source,yaml]
----
apiVersion: user.openshift.io/v1
kind: Group
metadata:
  name: cluster-admins
users:
- admin
----

. Log in to the Argo CD UI via the *OpenShift* button using your OpenShift admin credentials.
+
image::argo-cd-empty-ui.png[The Argo CD user interface after a fresh installation]

. Navigate back to the *All Clusters* view in RHACM and go to *Applications*. You should see options to create an *Argo CD ApplicationSet* for both Pull and Push models.

=== Deploying An Application Using Argo CD

For this exercise, we will use the Push Model.

. In RHACM, navigate to *Applications* and click *Create application -> Argo CD ApplicationSet - Push model*.
. **Name**: `rocketchat`
. For *Argo Server*, click *Add Argo Server*.
* **Name**: `argodemo`
* **Namespace**: `openshift-gitops`
* Click *ADD*.
+
image::add-argo-server.png[Adding a new Argo Server configuration]

. Once added, it should appear in the dropdown. Click *NEXT*.
. Under *Repository*, enter the following:
* **URL**: `https://github.com/levenhagen/rocketchat-acm.git`
* **Revision**: `main`
* **Path**: `rocketchat`
. Under *Destination*, set the *Remote namespace* to `default`.
. Click *NEXT* until you reach *4 Placement*.
. Select the `default` cluster set.
. Expand *Label expressions* and set the following:
* **Label**: `environment`
* **Operator**: `equals any of`
* **Values**: `prod`
+
image::argo-placement-label.png[Configuring placement rules with label expressions]

. Click *Next* to review and then *Submit*.
. Click on the *Topology* tab and watch as the application is deployed. The deployment is complete once all elements in the topology view are green.
+
image::app-topology-view.png[Application topology view during deployment]

. Once complete, you can click on the ApplicationSet in the topology view to see its status and launch the Argo CD editor.
